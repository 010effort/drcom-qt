# 吉林大学校园网认证客户端（Dr.COM / Qt）
基于 Qt 6 编写的吉林大学校园网 Dr.COM 认证客户端，带完整的图形前端页面。
## 功能
- 账号 / 密码 / MAC 地址登录认证
- MAC 地址自动获取（自动识别网卡）
- 记住密码、自动登录
- 连通性检测，断线自动重连（可开关）
- 独立「校园网址导航」对话框（吉大常用网站分类直达）
- 登录状态实时显示（未连接 / 认证中 / 已连接 / 已注销），显示服务器分配 IP
- 掉线自动提示，关闭窗口或点击最小化均隐藏到系统托盘，认证连接后台持续保活
- 保持唤醒（可选功能）；防系统睡眠，可选屏幕常亮，独立于登录状态，未认证也可从主界面或托盘开启
- 开机自启：优先创建「登录时触发」计划任务，权限不足时自动回退注册表启动项
- 界面深色模式：自动跟随系统主题，可在高级设置中手动切换
- 高级设置：认证服务器、端口、本机 IP、首选 DNS、主机名
